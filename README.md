# eCommerce

A bright, modern React eCommerce frontend powered by the DummyJSON API.

## Stack

- React 18
- TypeScript
- Vite
- DummyJSON API
- Lucide React
- CSS

## Run

```bash
npm install
npm run dev
```

## Features

- API products and categories
- Search
- Category filtering
- Sorting
- Favorites counter
- Shopping cart drawer
- Quantity controls
- Loading skeletons
- Error state
- Responsive mobile layout
- Component-based React + TypeScript structure
